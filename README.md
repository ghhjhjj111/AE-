AE 表达式入门实战：小莫课程精讲，表达式案例源码课件直接复用

AE 表达式入门最大的坑，是把学员带进“语法讲解”里出不来。看懂了 wiggle、time、value，一动手还是不知道往哪写。小莫课程的精讲思路是反过来的：先给可复用的案例，让学员先跑起来、先看到效果，再回头理解表达式在做什么。入门阶段不追求写复杂逻辑，而追求“能改、能调、能迁移”。心法可以概括为：案例先行，参数可调，源码可拆，课件可复用。

一、入门路径：从“复制能用”到“看懂会改”

表达式入门分三步走。第一步是复制可用：课程直接给已经调好的表达式案例，学员粘贴到对应属性上就能看到效果，先建立“表达式能干什么”的直觉。第二步是改参数：把案例里的频率、幅度、延迟、随机种子变成可调变量，让学员动手改数字，观察画面变化，理解每个参数控制什么。第三步是拆结构：把一个表达式拆成“取当前值、加随机、加时间、加条件”几个片段，讲清每段的作用，再让学员自己拼装。

这个路径的关键是每节课都有可见成果。第一课就能做出抖动、循环、跟随，学员才有动力继续。语法放到案例后面讲，一次只讲一个点，讲完立刻用在案例里。

二、核心案例：覆盖入门高频需求

入门案例不在多，在覆盖高频场景。第一类是随机抖动，用于镜头震动、灯光闪烁和位置扰动，重点是控制频率、幅度和是否平滑。第二类是循环动画，用于旋转、位移和缩放，重点是 loopOut 的几种模式和循环起点。第三类是时间驱动，用 time 做匀速运动、延迟触发和节奏变化。第四类是数值映射，用线性插值把一个范围映射到另一个范围，做音量驱动缩放、位置驱动透明度。第五类是条件判断，用 if 做阈值触发、状态切换和开关控制。第六类是文本与计数，做数字滚动、时间码和进度显示。

每个案例配一个“最小可用版”和一个“可调版”。最小版只保留核心表达式，方便理解；可调版把参数提到前面，加注释，方便学员改。案例之间要有递进：先单属性，再多属性联动，最后做图层之间的引用。

三、源码与课件：让复用真正发生

源码交付要方便复用，而不是方便讲师演示。每个案例单独一个工程文件，图层命名清晰，表达式写在对应属性上，关键参数用注释标出“改这里”。工程里保留一个“效果预览”合成，打开就能看到动画。表达式不要写得过于紧凑，适当换行，方便学员看懂结构。

课件按“效果展示、表达式拆解、参数说明、动手改一改、常见错误”五块组织。效果展示放 GIF 或短视频，让学员先看到目标；表达式拆解用分段高亮，讲清每段作用；参数说明列表讲清每个数字控制什么；动手改一改给三个小任务，比如把抖动幅度加大、把循环改成往返、把触发阈值调低；常见错误列出入门高频问题，比如表达式报错、属性类型不匹配、关键帧与表达式冲突、复制后引用错图层。

课件还要给“迁移指南”：同一个表达式怎么从位置迁移到缩放，从单图层迁移到多图层，从固定值迁移到引用滑块控制。学员学会迁移，才算真正掌握。

四、实战避坑：入门阶段最容易卡的地方

入门阶段常见坑有五个。第一，表达式报错不看提示，直接删掉重来，其实错误信息已经说明类型不匹配或语法问题。第二，表达式和关键帧冲突，不知道表达式会覆盖关键帧，要先关表达式再调关键帧。第三，复制表达式后引用错图层，图层名或索引变了，表达式指向错误对象。第四，维度不匹配，位置是二维数组，缩放是二维或三维，直接套用会报错。第五，性能问题，复杂表达式加在多个图层上导致预览卡顿，入门阶段尽量用轻量写法，必要时预渲染。

课程要教排查顺序：先看报错信息，再检查属性类型和维度，再检查引用对象是否存在，最后简化表达式分段测试。每节课留一个“故意写错”的案例，让学员练习排查。

AE 表达式入门的心法是：案例先跑起来，参数先改起来，结构再拆开，源码能迁移，课件能复用。小莫课程的精讲价值，不在于讲了多少语法，而在于让学员第一节课就能做出效果，第十节课就能改出自己想要的效果。入门不求写得多，求改得快、用得稳。
